# Regional Annotations

The project should support lightweight regional feedback on generated images so users can communicate *what* they like or dislike within a result, not just whether they like the image overall.

This should make it easy to express feedback such as:

* keep this character design;
* change this facial expression;
* use the lighting from this area;
* avoid this background treatment;
* combine this part of one image with that part of another.

Regional annotations are intended to make visual iteration more precise and expressive. They give the system a richer understanding of which parts of an image should be preserved, changed, or reused as inspiration.

Annotations should become part of the broader creative workflow in the same way as text feedback. They can help refine the next concept, preserve useful observations on an image for later reuse, support recombination across branches, and make the graph a record of visual reasoning rather than just image history.

The end goal is to let users guide image exploration with more nuance than simple image-level preference while keeping the interaction intuitive and visually driven.
